# 章节评估记录

## 1 使用方式

按 [章节评估流程](../CHAPTER_ASSESSMENT.md) 确认主题范围后，使用 [评估模板](../ASSESSMENT_TEMPLATE.md) 创建实际报告。文件名为 `YYYY-MM-DD-主题.md`，同日多次使用不同后缀；同一次评估跨会话继续时保留阶段日期和原始证据。

报告保存技能图、逐题表现、帮助情况、独立检查、等级变化和后续复习安排。[当前进度](../PROGRESS.md) 链接各主题最新报告，[学习暂存](../PENDING.md) 记录有日期的问答或阶段事件与报告链接。不要仅凭建立机制就创建已评估结果或给旧记录赋级。
